바이브 코딩이란

코드를 직접 쓰지 않고, 원하는 것을 말로 설명해 AI가 만들게 하는 방식

STEP 01

말로 요청

"나를 소개하는 홈페이지 만들어줘" 원하는 내용과 분위기를 문장으로 설명합니다.

STEP 02

AI가 코드 작성

AI가 HTML·CSS 코드를 직접 써서 파일로 만들어 줍니다.

STEP 03

확인하고 다시 요청

결과를 보고 "글씨 키워줘"처럼 고칠 점을 말하면 다시 고쳐 줍니다.

핵심 역량
코딩 실력보다 '무엇을 원하는지 정확히 설명하는 능력'이 결과를 좌우합니다.

홈페이지가 세상에 나오는 3단계

집을 짓고, 땅에 세우고, 주소를 받는 것과 같습니다

01 만들기

HTML 파일

홈페이지의 설계도이자 집 자체. 바이브 코딩으로 AI가 만들어 줍니다.

02 올리기

호스팅

24시간 켜져 있는 인터넷 서버에 파일을 올려 두는 일. 집을 세울 땅에 해당합니다.

03 주소

URL

누구나 접속할 수 있는 인터넷 주소. 예: 아이디.github.io/사이트이름

오늘 쓰는 조합
만들기는 Claude Code, 올리기와 주소는 GitHub Pages(무료)가 맡습니다.

비교해 본 도구 3가지

모두 '말로 만들어 인터넷에 올리기'가 가능하지만 역할이 다릅니다

A 올인원 빌더

Lovable

웹사이트에서 대화하면 AI가 만들고 바로 올려 줍니다. 화면 미리보기가 편하지만, 무료판은 하루·한 달 수정 크레딧이 정해져 있습니다.

B 호스팅 서비스

Netlify

다 만든 파일을 올려 주는 곳입니다. 만드는 기능은 따로 필요합니다. 무료판은 월 크레딧 안에서 배포 횟수가 제한됩니다.

C 오늘의 선택

Claude Code + GitHub

내 PC의 AI 개발자(Claude Code)가 만들고, GitHub가 무료로 보관·배포합니다. 수정 횟수 걱정 없이 계속 고칠 수 있습니다.

한눈에 비교

무료로 '계속 수정'할 수 있는지가 수업의 핵심 기준

왜 Claude Code + GitHub인가

비교 결과, 수업에 가장 잘 맞는 이유 4가지

4가지 이유
추가 비용 없이 계속 수정

Claude 구독 하나로 만들고 고치기를 반복합니다.

호스팅은 완전 무료

GitHub Pages는 공개 저장소의 정적 사이트를 무료로 올려 줍니다.

모든 수정 기록이 남는다

"어제 버전으로 되돌려줘" 한마디면 이전 상태로 돌아갑니다.

실무 표준 도구를 배운다

개발자들이 실제로 쓰는 Git·GitHub 흐름을 그대로 경험합니다.

오늘 쓰는 도구와 역할

어려운 이름이지만 역할로 기억하면 쉽습니다

개발자

Claude Code

말을 알아듣고 코드를 쓰는 AI. 파일 만들기부터 올리기까지 대신 해 줍니다.

기록장

Git

파일이 바뀔 때마다 '저장 지점'을 남겨 언제든 되돌릴 수 있게 합니다.

온라인 보관소

GitHub

내 파일과 기록을 인터넷에 보관하는 곳. 사이트에 직접 들어갈 필요는 없습니다.

무료 호스팅

GitHub Pages

보관소의 파일을 홈페이지로 열어 주고 주소를 만들어 줍니다.

기억할 한 가지
우리는 Claude Code에게 말만 합니다. 나머지 셋은 Claude Code가 다룹니다.

준비물

수업 전에 1번과 2번을 미리 해 오면 실습 시간이 넉넉해집니다

준비 01

Claude 유료 요금제

Pro 이상이면 Claude Code를 쓸 수 있습니다. 오늘 실습에서 유일한 비용입니다.

준비 02

GitHub 계정

github.com에서 무료 가입. 이메일 인증까지 마쳐 두세요. 아이디(영문)가 홈페이지 주소가 됩니다.

준비 03

PC 프로그램 3개

Claude Code Git GitHub CLI(gh) 실습실 PC에는 미리 설치되어 있습니다.

아이디 예시
아이디가 cnpgood이면 내 홈페이지 주소는 cnpgood.github.io/사이트이름

실습 1  깃허브 로그인

처음 한 번만 하면 됩니다 (약 1분)

  • STEP 01

    Claude Code 대화창에 입력하고 엔터

    ! gh auth login --web
  • STEP 02

    화면에 나온 8자리 코드를 복사

    예: ABCD-1234 형태. 15분 안에 입력해야 합니다.

  • STEP 03

    github.com/login/device 에 코드 붙여넣기

    Continue를 누르고 Authorize github를 누릅니다.

  • STEP 04

    Claude에게 "로그인 했어"라고 말하기

    Claude가 로그인 상태를 확인해 줍니다.

실습 2  홈페이지 만들기

원하는 것을 말로 설명합니다

이렇게 요청해 보세요

나를 소개하는 홈페이지 만들어줘. 이름, 전공, 관심 분야, 연락 버튼을 넣어줘.
흰 바탕에 남색 포인트로, 휴대폰에서도 잘 보이게 해줘.
다 만들면 바탕화면에 저장하고 브라우저로 열어줘.
확인 01

미리보기

바탕화면 파일을 더블클릭해 브라우저에서 확인

확인 02

고칠 점 메모

마음에 안 드는 곳을 한 문장으로 적어 두기

실습 3  인터넷에 올리기(배포)

한마디면 Claude Code가 저장소 만들기부터 배포 설정까지 처리합니다

이거 깃허브에 올려서 배포해줘
  • 자동 01

    저장소(Repository) 생성

    내 깃허브 계정에 사이트 이름으로 보관소가 만들어집니다.

  • 자동 02

    파일 업로드 + GitHub Pages 켜기

    1~2분 뒤 홈페이지가 열립니다.

  • 확인

    주소를 휴대폰으로 열어 보기

    https://아이디.github.io/사이트이름

실습 4  수정하고 되돌리기

말할 때마다 고쳐서 다시 올립니다. 1~2분 뒤 같은 주소에 반영

수정 요청

제목을 '반갑습니다'로 바꿔줘
프로젝트 소개 칸을 하나 추가해줘
버튼 색을 남색으로 바꿔줘
고친 거 깃허브에 다시 올려줘

되돌리기

아까 버전으로 되돌려줘
지금까지 수정 기록 보여줘

Git이 수정할 때마다 저장 지점을 남기기 때문에, 실수해도 언제든 이전 상태로 돌아갈 수 있습니다.

안 바뀌어 보이면
1~2분 기다린 뒤 새로고침(Ctrl + F5). 그래도 그대로면 Claude에게 그대로 말하세요.

좋은 요청 쓰는 법

구체적일수록 한 번에 원하는 결과가 나옵니다

아쉬운 요청

  • 예쁘게 만들어줘
  • 이상해, 고쳐줘
  • 다 바꿔줘

좋은 요청

  • 흰 바탕에 남색 포인트, 글씨는 크게
  • 휴대폰에서 메뉴가 겹쳐 보여. 한 줄로 정리해줘
  • 자기소개 문단만 3줄로 줄여줘
요청 공식
누구를 위한 + 어떤 내용 + 어떤 분위기 + 어디를 어떻게

주의사항

공개 홈페이지라는 점을 꼭 기억하세요

01

누구나 볼 수 있어요

무료 저장소와 홈페이지는 전체 공개입니다.

02

개인정보 금지

전화번호, 집 주소, 학번, 주민번호는 넣지 않습니다.

03

사진·글 저작권

직접 찍은 사진이나 무료 이미지만 사용합니다.

04

보여주는 사이트용

회원가입·로그인 같은 서버 기능은 지원하지 않습니다.

05

공용 PC는 로그아웃

다음 사람이 내 계정으로 올리지 않도록 꼭 로그아웃합니다.

06

반영은 1~2분

올린 직후 안 바뀌어도 잠시 기다린 뒤 새로고침합니다.

수업 마무리

내 주소를 공유하고, 공용 PC라면 로그아웃까지

  • CHECK 01

    내 홈페이지 주소를 채팅방에 공유

    서로의 주소에 접속해 보고 칭찬 한 줄 남기기

  • CHECK 02

    깃허브 로그아웃

    ! gh auth logout
  • CHECK 03

    Claude 로그아웃

    /logout

집에서 계속 고치고 싶다면 내 PC에 Claude Code를 설치하고 같은 방법으로 로그인하면 됩니다.
